## 二、目录与进程

| 项 | 位置 |
|---|---|
| 代码 | `/opt/aiframe`（server/、dist/、node_modules/） |
| 数据 | `/opt/aiframe/data/`（db.json + uploads/） |
| 服务名 | `aiframe.service` |
| 日志 | `/var/log/aiframe.log` |
| nginx 配置 | `/etc/nginx/conf.d/aiphoto.aimemory.cafe.conf` |
| 证书 | `/etc/letsencrypt/live/aiphoto.aimemory.cafe/` |

常用的几条命令：

```bash
systemctl status aiframe      # 看状态
systemctl restart aiframe     # 重启
tail -f /var/log/aiframe.log  # 看日志
curl -s localhost:4000/api/photos | head -c 200   # 本机探活
```

服务已 `enable`，机器重启会自动起来。

## 三、nginx 关键配置

两个地方是专门为这个应用调的，改的时候别丢掉：

```nginx
client_max_body_size 300M;    # 视频上传，默认 1M 会直接 413
proxy_read_timeout 300s;      # 视频转码慢，默认 60s 会掐断
proxy_request_buffering off;  # 大文件不要先落盘再转发
```

证书续期是 certbot 自动的（`systemctl list-timers | grep certbot` 能看到），
**别删 80 段里的 `/.well-known/acme-challenge/`**，删了续期就失败。

## 四、代码更新后怎么发

本地改完、`npm run build` 之后，重新上传 `server/` 和 `dist/` 再重启：

```bash
# 本地打包（排除 node_modules、data）
# 上传到 /opt/aiframe/ 覆盖 server/ 和 dist/
systemctl restart aiframe
```

`data/` 目录**永远不要覆盖**——里面是用户真实的照片和语音。

依赖有变化时才需要在服务器上跑：

```bash
cd /opt/aiframe && npm install --omit=dev --ignore-scripts --registry=https://registry.npmmirror.com
```

> ⚠️ 必须带 `--ignore-scripts`。`onnxruntime-node` 的安装脚本要连 GitHub 下二进制，
> 服务器连不上会报 `Failed to download build list` 整个安装失败。
> 跳过脚本不影响使用——包内自带 linux-x64 的二进制。

## 五、AI 配置（已开启）

现在用的是 **DeepSeek `deepseek-flash`**，配置在 `/opt/aiframe/.env`（权限 600）：

```ini
PORT=4000
HF_MIRROR=https://hf-mirror.com
AI_BASE_URL=https://api.deepseek.com/v1
AI_API_KEY=***        # 实际值在 .env 里
AI_MODEL=deepseek-flash
```

查看当前配置：

```bash
cat /opt/aiframe/.env | grep -v KEY     # 看配置但不打印 key
```

改完 `.env` 后执行 `systemctl restart aiframe` 生效。

### 关于模型选择

**`deepseek-flash` 能看图**，实测能准确描述画面内容（"深色底上有个浅色相框，里面一道折线像小山"）。

但要注意两点：

1. **它是推理模型**，会先输出 `reasoning_content` 再给答案，
   `max_tokens` 给小了（比如 220）会导致正文为空、只剩思考过程。
   代码里已设成 **1500**，别调小。
2. `deepseek-v4-pro` **看不了图**，会直接回答"我无法查看这张图片"。

代码里有防护：检测到模型拒绝看图时，自动退回「只用子女写的话」生成解说，
不会把"我看不了图片"这句话念给老人听。这个兜底对任何纯文本模型都有效。

### 换成更强的视觉模型

想更准（尤其复杂生活照），换阿里云百炼的 `qwen-vl-plus` 或智谱 `glm-4v`，
只改 `.env` 两行：

```ini
AI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
AI_MODEL=qwen-vl-plus
AI_API_KEY=新的key
```

### 还没配的

- **上传大小**：现在 300M。要传更长视频，三处同时改：
  `server/index.js` 的 multer limits、nginx 的 `client_max_body_size`。
- **备份**：`/opt/aiframe/data/` 是唯一有用户数据的地方，**目前没有自动备份**。
  建议加个每天打包传到 OSS 的定时任务——硬盘挂了这些照片和录音就没了。
