# AI 平板落地方案 v0.2 — 对标「主动式陪伴」模式

> 变更说明：v0.1 是按「纯语音主动搭话」设计的。对照行业标杆后发现**漏了最核心的一层：物理存在感**。本版补上，并修正战略定位。
> 日期：2026-11-02

---

## 1. 你看到的那个模式，拆开是四层

「小白」（绘话智能）的设计复盘里有一句话，是整个品类的灵魂：

> **工具只在你使用它的时候存在；伙伴在你没有使用它的时候也存在。它会眨眼、会打瞌睡、会转头看你。**

这句话解释了为什么"AI 平板"不等于"传统平板 + 感应器"。四层能力：

| 层 | 内容 | v0.1 覆盖情况 |
|---|---|---|
| **L1 感知** | 有人/无人、距离、停留时长（毫米波） | ✅ 已覆盖 |
| **L2 主动** | 在场足够久才开口，被无视就退回 | ✅ 已覆盖 |
| **L3 存在感** | 转头看你、待机眨眼、打瞌睡、呼吸灯、开关机身体动线 | ❌ **完全缺失** |
| **L4 记忆** | 记住上次聊的、第二天主动接上话题 | ⚠️ 没写，但你已有 AIMemory |

**L3 就是"这个模式"的爽点所在**，也是纯平板方案做不到的部分。一块不动的屏幕，无论语音多流畅，本质仍是"设备"，不是"伙伴"。

### 小白的 L3 是怎么做的（可直接抄的部分）

- **待机**：呼吸式灯光模拟"眨眼"；长时间无交互会间断做出"瞌睡"表情 —— 让"它在"这件事可见
- **对话**：识别到语音后**转头面向用户、抬头前倾**，模拟人类倾听姿态
- **开关机**：缓缓抬头（像从睡梦中苏醒）／缓缓低头（安静睡去）—— 状态切换不是"亮屏/熄屏"
- **形态**：蛋形、圆润无棱角、可倾斜颈部，织物扬声器格栅 —— 迎合家居，不侵入家居

对照一下：我们的方案目前是"黑遮罩的平板"，在 L3 上得分为零。

## 3. 33% 这个数字要读懂

**主动搭讪成功率 33%** —— 这是小白的公开实测数据，也是行业标杆。

意思是：**每 3 次主动开口，有 2 次被无视。**

这个数字有三层含义：
1. **这不是产品失败，是品类天花板**。"主动"本身不可能 100% 命中，因为人本来就经常不想说话
2. **所以"被无视"必须是设计的一部分**，不能是异常状态 —— v0.1 定的"5 秒无回应静默退回"是对的，要保留
3. **只靠"主动聊天"，商业价值有限**。聊完就没了，用户凭什么持续付费？必须有一个"主动之后产生什么"的钩子

第 3 点是关键。小白挂在"健康管理 + 子女连接 + 社区服务"上。**你挂什么？**

## 4. 方案修正：不做平板，做「云台底座」

对标 Eva 的思路，但加雷达、保留屏幕。这是 L3 的最便宜解法。

### 4.1 硬件清单

| 器件 | 型号 | 价格 | 备注 |
|---|---|---|---|
| 二轴云台 | 金属齿舵机 MG996R ×2（验证期） | ¥70 | ⚠️ 舵机有"吱吱"声，会破坏生命感。量产换步进电机+同步带或无刷伺服 |
| 主控 | ESP32-S3 | ¥50 | 驱动舵机 + 连雷达 + 发指令 |
| 人体雷达 | HLK-LD2410C | ¥40 | 检测有人/距离 |
| 呼吸灯 | WS2812 环形灯带 | ¥10 | **性价比最高的"生命感"，¥10 换 30% 观感** |
| 结构件 | 3D 打印夹持臂 + 底座 | ¥60 | 夹 10–11 寸平板，或磁吸手机 |
| 电源 | 5V/3A | ¥20 | |
| **合计** | | **¥250–350** | |

### 4.2 形态

```
        ┌──────────────┐
        │   平板 / 手机  │  ← 夹持或磁吸
        └──────┬───────┘
          ┌────┴────┐
          │  二轴云台 │     ← 水平 ±60°、俯仰 ±20°
          └────┬────┘
     ┌─────────┴─────────┐
     │  底座：ESP32+雷达   │
     │  + 呼吸灯环         │
     └───────────────────┘
```

**为什么这个形态比"做平板"好：**
- 成本 1/100：¥300 vs ¥25 万起
- 通用：夹任何平板、任何手机，用户自带算力
- 可验证：一周做出来，直接摆在桌上感受"它转头看我"的差异
- 可退可进：验证成功再考虑一体化外观

### 4.3 交互动作表（直接照小白的抄）

| 触发 | 云台动作 | 屏幕 | 灯光 |
|---|---|---|---|
| 有人进入 2m | 缓慢转向该方向 | 亮屏，显示"眼睛" | 呼吸灯渐亮 |
| 持续在场 8s | 抬头前倾 15°（倾听姿态） | 切换表情 | 保持 |
| 开始说话 | 保持不变 | 说话表情 | 随音量脉动 |
| 用户开口 | 小幅点头 | 聆听表情 | 稳定蓝 |
| 5s 无回应 | 缓慢回正 | 退回待机 | 缓暗 |
| 长时间无人 | 缓慢低头 | 瞌睡表情 | 极暗呼吸 |
| 开机 | 缓缓抬头 | 苏醒表情 | 渐亮 |

**这套动作就是 L3。做出来，产品从"设备"变成"伙伴"。**

### 4.4 补 L3 的优先级（按性价比排序）

1. **呼吸灯** ¥10 → 观感提升最大，先做
2. **待机眨眼**（屏幕亮度缓变，0 成本）→ 立刻就"活"了
3. **转头追人**（云台 + 雷达角度/视觉）→ 核心，但需要云台
4. **开关机身体动线**（缓缓抬头/低头）→ 仪式感，0 成本
5. **表情层**：只需 5 个（待机/聆听/思考/说话/瞌睡），**不要做 100 个**

## 5. 但真正能赢的不是这个 —— 定位换一下

这是本版最重要的一节。

**别人做"陪伴"，你做"记忆"。**

### 5.1 为什么这个切口成立

| | 小白 / Eva / Loona | 你 |
|---|---|---|
| 主动说什么 | "今天睡得怎么样？""腿还酸吗？" | "您上回说那个厂，是哪一年进的？" |
| 对话结束后 | **什么都没留下** | 变成文字、照片、书 |
| 用户为什么持续用 | 陪伴感（会衰减） | **有个东西在长出来** |
| 怎么赚钱 | 硬件 + 服务费 | 硬件平价 + **内容/照片书** |
| 谁能抄 | 谁都能做陪伴 | **只有你有 AIMemory** |

### 5.2 一句话产品定义

> **它不是"会聊天的平板"，是"放在家里、会主动问你往事、最后变成一本书的记忆采集终端"。**

三个推论：
- **主动搭话的性质变了**：从"闲聊"变成"采访"。目标是**掏出素材**，不是陪聊
- **33% 成功率不再是问题**：采访本来就是断断续续的，今天不接话，明天接着问
- **硬件可以不赚钱**：真正的收入在照片书和后续内容服务上 —— 这是小米、百度、阿里做不了的，因为它们没有 AIMemory 这条内容产线

### 5.3 生态协同终于说通了

之前三条线（AI Worker / AIMemory / AI Pad Mate）的关系是"互相采购"，比较虚。换成记忆定位后：

```
AI Pad（采集）→ 主动问往事 → 录音/照片/文字
      ↓
AIMemory（加工）→ 整理成回忆录 → 排版 → 照片书/画册
      ↓
AI Worker（分发）→ 生产推广内容 → 获客
      ↓
（回到 AI Pad 卖出去更多）
```

**这是一条真实的、每环都在产生价值的链路，而不是为了刷交易量做的内部采购。**

## 6. 修正后的路线

### P0｜1 周｜¥200｜先别做云台

还是先用现有平板跑纯语音版（v0.1 的方案）。**目的不是验证产品，是验证你的技术链路能不能跑通**（雷达 → App → ASR/LLM/TTS），顺便暴露 AEC、息屏唤醒两个坑。

> 不要跳过这步直接做云台。云台会引入电机噪声（干扰麦克风）、供电、结构三个新变量，链路没通就上，会分不清是谁的问题。

### P1｜2 周｜¥500｜加云台，验证"存在感"

- 加二轴云台 + 呼吸灯
- 做 4.3 那张动作表
- **对比测试**：同一套语音能力，"会转头" vs "不转头"，你自己坐 3 天，感受差多少
- 这个对比的结论，比任何调研都值钱

### P2｜4 周｜¥2 万｜换定位，验证"记忆"

- 把主动话术从"闲聊"改成"采访"（用《我的好爸爸》10 篇做话题库原型）
- 跑 10 户真实家庭 30 天
- **核心指标不是"接受率"，是"沉淀率"**：30 天里产生了多少条可用素材？有没有人愿意为成书付钱？

### P3｜3 个月｜¥10 万｜产品化

- 静音云台（步进/无刷）、一体外壳、认证
- 依然不自研平板：夹持式，用户自带设备

## 7. 必须承认的三个风险

1. **L3 做不好会更糟**。一个动作僵硬、转头发响的"伙伴"，比一个不动的屏幕更让人出戏。云台是双刃剑，宁可动作慢一点、软一点，也不要快而硬
2. **"记忆采集"这个定位需要教育成本**。用户第一眼看到的是"会说话的平板"，不是"采访机"。话术和包装要下功夫
3. **对标产品已经很强**。小白有 565 个社区渠道和政府背书，阿里有 899 的价格和钉钉生态。你赢不了渠道和价格，**只能赢"内容产出"这一件事**
