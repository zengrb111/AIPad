# 装到设备上

一共两个 App，装的地方不一样：

| App | 装在哪 | 谁用 | 包名 |
|---|---|---|---|
| **相框** | 家里的平板 | 爸妈 | `cafe.aimemory.frame` |
| **爸妈的相框** | 子女的手机 | 你 | `cafe.aimemory.family` |

两个包的包名不同，**可以装在同一个手机上**（比如你自己先两边都装上试）。

Android 用装 APK 或 Chrome 安装；iPad 只能用 Safari 添加到主屏幕（原因见下）。

| 设备 | 推荐方式 | 需要什么 | 时间 |
|---|---|---|---|
| **iPad**（相框端） | Safari 添加到主屏幕 + 引导式访问 | 什么都不用装 | 5 分钟 |
| **Android 平板**（相框端） | 装 `相框.apk`，或 Chrome 安装应用 | 拷个文件 | 2 分钟 |
| **Android 手机**（子女端） | 装 `爸妈的相框.apk` | 拷个文件 | 2 分钟 |
| **iPhone**（子女端） | Safari 打开 `/family` 添加到主屏幕 | 不用装 | 1 分钟 |

> **iOS 没有真 App 的路。** 打 iOS 包必须有 macOS + Xcode + 苹果开发者账号（$99/年），
> 在 Windows 上做不出来。iPad 只能用「添加到主屏幕」，但配合引导式访问，
> 效果和原生 App 几乎没区别。

---

## 一、iPad（推荐，最快）

### 1. 添加到主屏幕

1. 用 **Safari**（必须 Safari，Chrome 不行）打开相框地址，例如 `https://192.168.1.5:4000/frame`
2. 点底部的「分享」按钮
3. 往下找「**添加到主屏幕**」
4. 名字改成「相框」，点「添加」

桌面上会出现一个图标，点开是全屏的，没有地址栏，没有 Safari 的工具栏。

### 2. 关掉自动锁屏

设置 → 显示与亮度 → **自动锁定 → 永不**

不关的话 iPad 会自己黑屏，相框就"死"了。

### 3. 打开引导式访问（关键）

这一步是让 iPad 变成一个"只能显示相框"的设备，防止老人误触退出去：

1. 设置 → 辅助功能 → **引导式访问** → 打开
2. 设置一个密码（自己记住）
3. 回到桌面，打开相框，**连按三下侧边键**（或 Home 键）
4. 点「开始」

之后这台 iPad 就锁在相框里了，退不出去。要退出再连按三下 + 输入密码。

**这一步比什么设置都重要。** 老人拿到 iPad 最容易干的事就是乱滑退出，一旦退出，相框就再也不会自己回来。

### 4. 充电

iPad 带电常亮会一直充着。建议：
- 用原装充电器，别用劣质头
- 每隔两三个月看一眼电池有没有鼓包

## 二、子女的手机

### Android 手机

1. 把 `release/爸妈的相框-v1.0.apk` 传到手机上（微信发文件、数据线、网盘都行）
2. 点开安装，允许「安装未知来源应用」
3. 第一次打开会让你填服务器地址，见第四节

### iPhone

App Store 里没有，也装不了 APK。用 Safari 打开子女端地址再添加到主屏幕：

1. Safari 打开 `https://192.168.1.5:4000/family`
2. 分享 → 添加到主屏幕
3. 名字改成「爸妈的相框」

功能完全一样，就是没有推送通知（要推送得打原生包）。

## 三、相框平板（Android）

### 方式 A：Chrome 安装（推荐）

1. Chrome 打开 `https://192.168.1.5:4000/frame`
2. 右上角三个点 → 「**安装应用**」或「添加到主屏幕」
3. 桌面出现图标，点开是全屏独立窗口

Chrome 会把 PWA 装成一个真正的应用（WebAPK），有图标、有独立任务，和原生 App 用起来一样。

### 方式 B：装 APK

见下面第四节「自己编 APK」。

### 方式 C：Fully Kiosk Browser（做展示机/相框最省心）

如果这台平板是**专门当相框用**、不给人干别的，装 Fully Kiosk Browser：

1. 装 Fully Kiosk Browser（免费版够用）
2. 起始页填相框地址
3. 打开这几个开关：
   - **Keep Screen On**（屏幕常亮）
   - **Launch on Boot**（开机自启）
   - **Kiosk Mode**（锁定，禁止退出）
   - **Autoplay Media**（自动播放，省掉「轻触屏幕」那一步）
   - **Allow Microphone**

这套配置比自己写 App 还稳，而且把「息屏叫不醒」「被系统杀掉」「重启不回来」三个问题一次解决。

## 四、自己编 APK

工程已经配好了，在 `android/` 目录。相框 App 需要的原生能力都写进去了：
屏幕常亮、全屏、允许自动播放、录音权限、横竖屏自适应。

### 路线 1：Android Studio（推荐，最省心）

1. 下载安装 [Android Studio](https://developer.android.com/studio)（自带 JDK 和 SDK）
2. 打开 `D:\OPCProjects\AIPad\android` 这个目录
3. 等它自动同步（第一次会下载 Gradle 和依赖，十分钟左右）
4. 菜单 Build → **Build Bundle(s) / APK(s)** → **Build APK(s)**
5. 生成的 APK 在 `android/app/build/outputs/apk/debug/app-debug.apk`

把 APK 拷到平板，允许「安装未知来源应用」，装上就能用。

### 路线 2：命令行

需要 JDK 17+ 和 Android SDK。

```bash
# 在项目根目录
npm run build          # 先出网页产物
npx cap sync android   # 同步到 Android 工程
cd android
./gradlew assembleDebug
```

产物同样在 `android/app/build/outputs/apk/debug/`。

环境变量：

```bash
JAVA_HOME=<JDK 17 目录>
ANDROID_HOME=<Android SDK 目录>
```

SDK 需要装这几项：

```
platform-tools
platforms;android-35
build-tools;35.0.0
```

### 改成正式版（可选）

debug 包能装但体积大、没签名。要正式包：

1. 生成签名文件
2. 在 `android/app/build.gradle` 里配 `signingConfigs`
3. `./gradlew assembleRelease`

这一步等真要发给别人用的时候再弄。

## 五、装好之后填服务器地址

APK 第一次打开会让你填服务器地址（浏览器/PWA 不需要，因为本来就是从服务器打开的）。

在跑服务的电脑上，启动后终端会打出：

```
相框端   https://192.168.1.5:4000/frame
```

把 `https://192.168.1.5:4000` 这一段（**不要带 `/frame`**）填进 App，点「连接」。

连不上通常是这三个原因：

1. 平板和电脑不在同一个 WiFi
2. 电脑防火墙拦了 4000 端口
3. 地址少了 `http://` 或 `https://`
