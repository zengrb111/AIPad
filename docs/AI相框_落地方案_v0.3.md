## 2. 你的判断是对的，但理由和你想的可能不同

你说"还是做陪伴，记忆也默认就有的了"。这个判断成立，原因有三：

1. **用户不会为"记忆"付钱，但会为"陪伴"付钱**。记忆是结果，不是需求。老人不会说"我要被记录"，会说"我想有人说说话"——掏钱的是子女，子女买的也是"爸妈不孤单"，不是"我家的档案库"。
2. **记忆是留存钩子，不是获客钩子**。它决定用户 3 个月后还在不在，但决定不了他第一天买不买。
3. **HeyBondi 自己就是这么做的**。它官网有一句："**Get to know Mom & Dad all over again**"——你选一个问题，Bondi 去问爸妈，答案变成一本 **family book**。它把"记忆"做成了子女端的玩法，**但对外卖的是陪伴**。

所以：**对外讲陪伴，对内做记忆。两条腿，一张嘴。**

## 3. 形态修正：不是平板，是相框

这一点比"能不能加感应"重要得多。六个理由：

| # | 平板 | 相框 |
|---|---|---|
| 1 | "要用的设备"——不用的时候它就"不在" | "不用的家具"——**放着就在，天然对应"伙伴在你没使用它时也存在"** |
| 2 | 横屏手持，老人学不会 | 竖立常亮，**零学习**：插电、联网，剩下只有看和说 |
| 3 | 有"被拿起"的预期，逼近感强 | 无操作预期，安静待着才不打扰 |
| 4 | BOM ¥1000+ | BOM **¥300–600** |
| 5 | 是"设备"，自己买给自己 | 是"礼物"，**子女买给父母** —— 决策者和使用者分离，最好的生意结构 |
| 6 | 只有桌面一个位置 | 床头、柜子、电视柜、玄关，家里有 3–4 个自然位置 |

第 5 条是决定性的。**平板是自购，相框是送礼。** 送礼场景下，价格敏感度低、情感溢价高、传播靠"我妈收到哭了"这种叙事——这正是 HeyBondi 在社媒上做的（591 万播放那条是"孩子不想离开外婆家"）。

## 4. 撤回 v0.2 的云台方案

v0.2 我建议加二轴云台、转头看你。**这个建议对相框是错的，撤回。**

原因：云台属于「机器人」语言——会动的、有意图的、可能盯着你的。相框属于「家具」语言——静止的、被动的、不注视的。

**在老人卧室里放一个会转头的东西，和一个静静立着的木框，心理距离完全不同。** HeyBondi 明确写"No camera"，也是同一个逻辑：**降低被注视感**。

所以：
- ❌ 二轴云台、转头追人
- ✅ 保留：呼吸灯（相框边缘）、息屏唤醒、待机时的微光变化
- 相框的"存在感"不靠动作，靠**"它一直在那儿，照片一直在换"**

## 5. 最关键的洞察：话头从照片里来，不从雷达里来

这是 v0.1/v0.2 都没想明白的地方。我一直在琢磨"人来了该说什么"，但答案是：**说照片**。

HeyBondi 官网的例子：

> 照片里是孙子 Leo 在烤饼干 →
> AI 主动开口：**"Leo 又烤饼干了！要不要把你的饼干配方发给他？"**

对比一下：
- ❌ "今天过得怎么样？"（凭空搭话，尴尬，33% 成功率就是这么来的）
- ✅ "Leo 又烤饼干了，要不要把你的配方发给他？"（有具体锚点，接话成本极低）

**雷达只回答"现在能不能说"，照片回答"说什么"。**

这一条改变了整个技术优先级：

| 能力 | v0.1/v0.2 的优先级 | 正确优先级 |
|---|---|---|
| 人体感应 | ★★★★★ | ★★★（决定"何时"，不决定"说什么"） |
| 照片理解（识人、识场景、识关系） | 没写 | ★★★★★（决定"说什么"） |
| 家庭关系图谱 | 没写 | ★★★★★（"这是谁"决定称呼对不对） |
| 语音合成自然度 | ★★★ | ★★★★（讲照片要像讲故事） |

**如果只能做好一件事，做照片理解，不是做感应。**

## 6. 人体感应的正确角色

感应不是"触发器"，是"开关"。三个状态：

| 状态 | 条件 | 设备行为 |
|---|---|---|
| **无人** | 雷达 > 3m 且持续 2 分钟 | 屏幕变暗/息屏，停播，只保留极弱呼吸灯 |
| **在场** | 有人 0.5–3m | 亮屏，**开始播报**（讲照片、讲留言、讲天气） |
| **靠近** | <1m 且停留 >3s | 从"播报"切到"对话模式"，音量降低，等对方开口 |

为什么这样设计：
- **没人时说话是纯浪费**，也是家人反感的来源（"它自己在屋里说话"）
- **有人时不该沉默**——相框的价值是"主动讲"，等人开口就退化成智能音箱了
- **靠近时才对话**——距离是最自然的意图表达，不用唤醒词

**"主动发起语音聊天"的正确理解：不是人一靠近就聊天，是人一靠近它就开始讲，人凑近了才变成聊。**

## 7. 技术路线：三步，从改装到自研

### 7.1 P0｜1 周｜¥300–800｜买现成的安卓相框改装

**这是最重要的一步，也是最容易被跳过的一步。**

淘宝/1688 搜「**安卓数码相框 10寸**」「**云相框 安卓系统**」，¥300–800，能装 APK。买一台，把 App 装进去，套个木框，就是 heyparent 的中国版雏形。

- 优点：零硬件开发，一周出成品，能直接摆给爸妈用
- 缺点：BOM 高，不能量产
- 目的：**验证"相框形态 + 主动讲照片"这件事成不成立**，不是做产品

如果这一步都不成立，后面全省了。

### 7.2 P1｜3–4 周｜¥1500｜加感应，做成独立小盒

不改相框本体，外挂一个感应盒：

| 器件 | 型号 | 价格 |
|---|---|---|
| 主控 | ESP32-S3 | ¥50 |
| 人体雷达 | HLK-LD2410C（24GHz，能测静止） | ¥40 |
| 呼吸灯 | WS2812 环 | ¥10 |
| 电源+壳 | | ¥50 |
| **合计** | | **¥150** |

通过 WiFi/MQTT 通知相框 App 切换状态。**先不要用摄像头做视觉感应**——隐私是这类产品的生命线，HeyBondi 明确写"No camera"。

> 另一个可选路径：有现成开源方案（ESP32-S3 + LVGL + MQTT + Flask，BOM 约 ¥200，GPL 3.0，含原理图/PCB/BOM/3D 模型/固件/上位机）。如果后面要压成本，这是最好的起点——但它跑不动 ASR/LLM，只能做"屏 + 联网 + 播放"，智能全在云端。

### 7.3 P2｜2 个月｜¥5 万｜自研主板，压 BOM

- 方案：**RK3566 / RK3326 安卓核心板 + 10.1" 屏**
- BOM 目标：**¥400–600**（核心板 ¥150 + 屏 ¥150 + 壳 ¥80 + 电源/结构 ¥100）
- 为什么选安卓而不是 ESP32：**你的团队是软件背景，AIMemory 是 Taro + Capacitor，安卓方案能直接复用**。ESP32 要写 C/LVGL 固件，等于新建一个技术栈
- 打样 20 台，找深圳方案商（搜"RK3566 核心板 定制"），你出 ID 和软件，他们出硬件

### 7.4 P3｜量产

只做外壳和结构的迭代，主板继续用现成核心板。**永远不要自己设计屏幕和电池。**
