两个 App 都已经用同一张证书签好名了，产物在 `release/`：

| 文件 | 包名 | 大小 |
|---|---|---|
| `相框-v1.1.apk` | `cafe.aimemory.frame` | 3.3 MB |

## ⚠️ 二、这个文件丢了，App 就死了

`aiframe-release.jks` 是这两个 App 在安卓世界的身份证。**一旦丢失：**

- 已经装出去的所有设备，永远无法升级到这个 App 的新版本（系统会因为签名不一致拒绝安装）
- 没法上应用商店，也没法发新包
- 只能换包名重新发一个"新 App"，老用户得手动卸载重装

**现在就做三件事：**

1. 把 `aiframe-release.jks` 和 `keystore.properties` 拷到 U 盘 / 网盘 / 密码管理器
2. 至少存两处，其中一处不在你现在这台电脑上
3. 密码和文件分开存（文件泄露但没密码没用，密码泄露但没文件也没用）

---

## 三、改代码后重新打包

```bash
npm run apk
```

一次出两个签名包，自动覆盖 `release/` 下的文件。

如果只改了一端，也会两个都编——反正只要一分多钟，别手动挑。

## 四、版本号规则

在 `android/app/build.gradle` 里：

```gradle
versionCode 2        // 整数，每次发版必须 +1，安卓靠它判断新旧
versionName "1.1"    // 给人看的
```

**`versionCode` 只增不减。** 如果发出去的版本号比设备上装的小，系统不会让你覆盖安装，用户也不会收到更新。

建议规则：

| 改动 | versionName | versionCode |
|---|---|---|
| 修 bug | 1.1.1 | +1 |
| 加功能 | 1.2 | +1 |
| 大版本 | 2.0 | +1 |

## 五、以后要上应用商店

现在这套配置可以直接用，但上架前还要补：

- **软著**：国内应用商店基本都要（约 1–2 个月，¥300–1000 代办）
- **隐私政策**：必须有独立页面，说明收集了哪些信息（照片、录音、麦克风）
- **权限说明**：RECORD_AUDIO 要在商店后台写清楚为什么需要
- **App 备案**：2023 年起国内要求 App 做备案，和域名备案是两回事，周期约 2 周

如果要上 Google Play，还要注意 targetSdk 必须跟上当年要求（现在 36 没问题）。
